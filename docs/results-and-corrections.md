# Results and corrections

This page collects the results that bolzakit computes or relies on which correct, sharpen or add to the literature and
to the math-pursuits notes it was built from. Each item gives its source and how bolzakit checks it.

## 1. Aut⁺(Bolza) ≅ GL(2,3), not S₄×ℤ₂

**The literature statement.** Strohmaier–Uski 2013 §7.1 [SU13] say: "The Bolza surface has symmetry group S4 ×Z2 .
Its order, 48, thus maximizes the order of the symmetry group (of orientation preserving isometries) amongst all genus 2
hyperbolic surfaces."

**The correction.** The order, 48, is right. The group is GL(2,3), which is not isomorphic to S₄×ℤ₂:

- Every element of S₄ has order 1, 2, 3 or 4. So every element of S₄×ℤ₂ has order dividing lcm(4, 2) = 4, or order
  3 or 6. There are no elements of order 8.
- bolzakit computes Aut⁺ = N/Γ exactly, where N is the (2,3,8) triangle group generated by Γ, the rotation ρ by π/4
  about the octagon centre, and a half-turn σ. The element orders are
  `{1: 1, 2: 13, 3: 8, 4: 6, 6: 8, 8: 12}`. Twelve elements have order 8 (ρ is one of them).
- `automorphisms().isomorphism_to_GL23()` gives an explicit map to GL(2,3). `tests/test_automorphisms.py` checks that
  it is a bijective homomorphism.

With the reflection z ↦ z̄ the full isometry group has order 96 (`full_order`).

Label: PROVED (exact normaliser check plus exact enumeration of the quotient; item 02).

## 2. Strict fractionality of τ(P₋(h)) (math-pursuits item 04)

Source: `math-pursuits/items/04-kadison-kaplansky-strict-fractionality/work/note.tex`, Theorem 1.

**Setting.**
- Γ is a discrete group, C*_r(Γ) its reduced group C*-algebra, and L(Γ) its group von Neumann algebra.
- τ(a) = ⟨a δ_e, δ_e⟩ is the canonical trace.
- P₋(h) = 1_{(−∞,0)}(h) is the negative spectral projection.

**Theorem.** Let Γ be a torsion-free cocompact Fuchsian group, for instance the Bolza group.

- **C1.** The Baum–Connes assembly map μ: K^Γ_*(E̲Γ) → K_*(C*_r(Γ)) is bijective.
- **C2.** τ_*(K₀(C*_r(Γ))) ⊂ ℤ. Hence C*_r(Γ) contains no projection other than 0 and 1 (Kadison–Kaplansky).
- **C3.** Every self-adjoint h ∈ C*_r(Γ) has connected spectrum.
- **C4** (for any discrete group). If h = h* ∈ L(Γ), h ≠ 0 and τ(h) = 0, then 0 < τ(P₋(h)) < 1.
- **C5.** If h = h* ∈ C*_r(Γ), h ≠ 0 and τ(h) = 0, then P₋(h) ∈ L(Γ) \ C*_r(Γ), and spec(h) = [a, b] with
  a < 0 < b. In particular 0 ∈ spec(h): h has no spectral gap at 0.

Since ℂΓ ⊂ C*_r(Γ), C4 and C5 apply to every nonzero self-adjoint trace-zero h in the group ring.

**How it is proved (from the note).**
- C4 uses only faithfulness of τ. If τ(P₋) = 0 then P₋ = 0, so h ≥ 0 with τ(h) = 0, which forces h = 0.
- C1 is the Baum–Connes conjecture for hyperbolic groups. The note applies Lafforgue [Laf12, Théorème 0.4] to the
  orbit Γz₀ ⊂ H²; alternatively, Γ is word-hyperbolic and Mineyev–Yu [MY02, Thm 20] applies.
- C2 is the Kadison–Kaplansky conjecture. [MY02, Thm 21] states: "The Kadison-Kaplansky conjecture holds for any torsion
  free subgroup G of a hyperbolic group, i.e. there exists no non-trivial projection in the reduced group C ∗ -algebra
  Cr∗ (G)."
- C3 follows from C2 by continuous functional calculus. C5 needs both C4 (so that P₋(h) ≠ 0, 1) and C2/C3 (so that
  P₋(h) ∉ C*_r(Γ) and the spectrum is an interval).
- The note's proof of the trace integrality in C2 also uses Lück's theorem relating Baum–Connes to the trace conjecture,
  and its Proposition on the element h^Γ uses Jolissaint's property (RD). bolzakit's docs do not rely on those two
  citations; see the note for them.

**Novelty.** The note says the ingredients are known and the corollary is "a short (folklore-level) observation". No
novelty is claimed.

**In bolzakit.** `spectral.tau_bounds` computes certified bounds on τ(P₋(h)) for elements h of this kind. The theorem
explains why no such element can have τ(P₋(h)) ∈ {0, 1}. For the systole shell the certified interval is [0.40993, 0.5].

## 3. Length-spectrum multiplicities: rounding bound 1.1e-8

Multiplicities of the primitive length spectrum come from exact half-traces and a float sum that must be an integer
([exact.md](exact.md)). Over all 42 lengths up to half-trace 120, the largest distance from an integer is 1.09e-8 (at
half-trace 59 + 42√2). That is why `lengths` is labelled NUMERICAL with "integrality residual ≤ 1.1e-8" and not EXACT.
The Selberg trace formula balances to ~1e-16 with these counts at t = 0.5, and only with the oriented convention.

## 4. Covering radius of the Weierstrass charts: 0.4056

The Green's function is validated in charts of Poincaré radius 0.45 centred at the six Weierstrass points. The covering
radius of those charts is

  ρ = max_z min_i |z_local,i| = 0.4056164   (Poincaré distance 0.8607).

The worst point is z = 0.374741 + 0.155223i in the octagon, at argument π/8 (equivalently −0.155223 + 0.374741i at 5π/8,
as recorded in `green/surface.py`). It is equidistant from the centre chart and two edge-midpoint charts. While writing
these docs we re-derived the value by maximising over the octagon with Nelder–Mead and got 0.4056164008 at argument
π/8 to 1e-11.

Since ρ < 0.45, every single point of the surface is valid. `robin_mass(z)` never raises. Only a pair of points with no
common chart makes `G(z, w)` raise `OutOfValidityRange`.

Status: NUMERICAL (a float64 optimisation, not a certified bound).

## 5. C₈ splitting of the N = 7 ring mode: about 1000·ξ⁴

At a Bolza Weierstrass point the surface has C₈ symmetry, while a 7-ring has C₇ symmetry. The charge-8 Taylor terms of
the regular part satisfy 8 ≡ 1 (mod 7), so they break the degeneracy between the cos(3θ_k) and sin(3θ_k) copies of
the radial m = 3 mode, giving a split of order ξ⁴ (≈1000·ξ⁴ in C1 units). bolzakit measures

  `ring(7, xi, "bolza").split(3)` ≈ 1000·ξ⁴   (1.006e-5 at ξ = 0.01 with D_ball = 13; 1.015e-5 at D_ball = 15).

The tests check 900 < split(3)/ξ⁴ < 1100. The (AI) code review of this module found the split independent of the
finite-difference step. Item 03's AI second reader measured the O(ξ⁴) tangential-force residual of the ring (ratio 256 between
ξ = 0.01 and 0.04); the size of the mode splitting is not recorded in math-pursuits item 03; no literature search was done. `modes()` returns the mean of the two copies, which is what the λ₃ series
describes.

Label: NUMERICAL.
